# Hi, I'm Santhosh 👋

**Full Stack Engineer at Delta Electronics, Bengaluru.**

I build software that runs on machines people depend on — React operator UIs, Node APIs, and the
embedded Linux underneath them.

platform**: a React touch-panel UI that operators use on the device itself, a browser-based admin
console, and the TypeScript/Node backend serving both — shipping on customer hardware.
